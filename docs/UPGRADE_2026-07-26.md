## 三、架构升级

1. **分层违规清除**：
   - `AdminManageController` 不再直连 `VipLevelMapper`——VIP 等级 CRUD 下沉至 `VipService`（新增 `listAllLevels/createLevel/updateLevel/deleteLevel`）。
   - `AIDataController`（145 行业务算法在控制器里）重构为薄路由，算法迁入新建的 `TravelInsightService/Impl`（热点 haversine 统计、常走路线聚合、文化短句），魔法数字提为命名常量。
2. **依赖倒置修复**：`OrderServiceImpl` 注入的 `PricingServiceImpl/BillingServiceImpl` 具体类改回接口注入；根因是 `PricingService` 接口缺 `calcCouponDiscount` 声明——已补。
3. **控制器减脂**：删除 AdminManageController 中 11 个从未使用的 `Authentication` 参数；VIP 写操作补 `@LogOperation` 审计注解（对齐其余管理端点惯例）。
4. **前端路由鉴权重构**：三份硬编码路由名数组（约 35 行）替换为父路由 `meta.requiresAuth` 继承 + `AUTH_CONFIG` 查表（7 行）。新增页面自动继承鉴权，从机制上消灭"漏配鉴权"这类错误。

## 四、UI 升级（收敛统一）

1. app-* 页面骨架类补齐（见缺陷 #1）——一次修复令 22 个页面恢复卡片层次、阴影与呼吸感。
2. 设计 token 扩充：新增 6 个语义渐变 token（`--gradient-primary/blue/violet/gold/deep-blue/brand-violet`）。
3. 硬编码渐变收敛：Home、VipCenter、Payment、AiAssistant、CampaignList、CampaignDetail、LandmarkExplore 共 7 个文件中与 token 逐字重复的渐变全部改为 `var()` 引用（消除双份定义漂移风险）。数据层色值（echarts 配置、VIP 五档等级色、城市地标配色表中无 token 对应者）判定为合理保留。

## 六、明确不做的事（及理由）

- **不拆 OrderServiceImpl（730 行）**：状态机 + 幂等 + 事件溯源高内聚，拆分收益 < 回归风险。
- **不改 Element Plus 为按需引入**：已有 manualChunks 分包缓解；改造需动几十个文件，性价比低。
- **不做 JS→TS 迁移**：65 文件全量迁移超出本轮价值边界，列入可选优化。
- **不重写 UI 视觉方向**："水墨江南"是有观点的设计语言，符合反模板原则，应收敛而非推翻。
- **保留 `catch {}` 惯例**：错误提示由 axios 响应拦截器统一弹出，本地空 catch 是既定架构。
