## 简历版本（150-250 字，可直接放入简历）

> **江南出行智慧调度系统** | 全栈开发 + 分布式调度设计
>
> 从零设计并实现了一个网约车调度平台（Spring Boot + Vue3 + MySQL + Redis Redisson），覆盖乘客端、司机端、管理后台三端，98 个 API 端点，27 张业务表。
>
> 核心解决了多订单并发的分配一致性问题：通过**二阶分布式锁**（订单锁 + 司机 tryLock + fallback）在 100 订单 × 20 司机压测中实现**零重复分配、零死锁**。设计了**可收敛的动态评分引擎**——加权评分叠加反馈学习与时间衰减——5 轮派单后成功率从 50% 收敛至 70%。全系统采用**形式化状态机**（10 状态 + 15 路径）和**事件溯源**（12 类事件覆盖全流程）。
>
> 完整实现了三层可观测性体系（Metrics / Health / Anomaly）、支付重试机制、自动计费系统和三端 JWT 鉴权。全程使用 AI 辅助开发（Claude Code），建立了 20 条规则约束 AI 行为，实现"人类主导 + AI 增强"的工程实践。
>
> *技术栈：Java 17 / Spring Boot 3.2 / MyBatis-Plus / Redis Redisson / MySQL 8.0 / Vue 3 / Docker*
