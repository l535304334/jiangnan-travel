# 江南出行 — UI/UX 规范

> 基于 Design System v2.0

---

## 一、导航规范

### 1.1 用户端
- **顶部 Header**：标题 + 消息中心入口 + 用户头像下拉菜单
  - 消息中心：Bell 图标 + 红点数字角标
  - 用户菜单：切换账号 / 退出登录
- **底部 Tab**（4项）：
  1. 首页（Home图标）
  2. 出行（Car图标 — 合并下单+订单）
  3. 发现（Compass图标 — 活动+文旅）
  4. 我的（User图标）

### 1.2 司机端
- **顶部 Header**：标题"江南出行·司机端" + 在线/离线开关
- **底部 Tab**（4项）：
  1. 接单（List图标）
  2. 行程（MapLocation图标）
  3. 收入（Money图标）
  4. 我的（User图标）

### 1.3 管理端
- **左侧固定侧边栏**（200px，深色背景 `#1A2332`）：
  1. Logo区（50px高）
  2. 菜单项（图标+文字，14px字号）
    - 数据大屏
    - 用户管理
    - 司机管理
    - 订单监控
    - 风控告警
    - 定价管理
    - 活动管理（新增）
    - 系统设置（新增）
- **顶部二级导航**：管理员姓名 + 退出按钮

## 二、页面布局规范

### 2.1 通用页面结构
```
┌─────────────────────┐
│      Header         │  ← 固定顶部
├─────────────────────┤
│                     │
│      Hero/搜索      │  ← 可选的关键操作区
│                     │
├─────────────────────┤
│                     │
│     内容区          │  ← 可滚动的卡片列表
│                     │
├─────────────────────┤
│      Bottom Tab     │  ← 固定底部（用户/司机端）
└─────────────────────┘
```

### 2.2 卡片列表规范
- 卡片间距：12px
- 卡片圆角：12px
- 卡片内边距：16px
- 列表最后一项无底部分割线
