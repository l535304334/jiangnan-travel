# 文档使用指南

> 不是所有文档都要读。按场景选，5 分钟找到你需要的。

---

## 按场景导航

### 🎓 场景 A：研究生复试准备（最重要）

**推荐顺序，约 2 小时准备完：**

```
Step 1:  README.md                                  (5min)  了解项目全貌
Step 2:  docs/interview/interview_script.md          (20min) 背 3min + 5min 稿
Step 3:  docs/interview/interview_qna.md             (30min) 过一遍 8 个问答
Step 4:  docs/interview/project_highlights_interview.md (20min) 记 6 个亮点关键词
Step 5:  docs/architecture/interview_architecture.md (10min) 练白板画图
Step 6:  docs/resume/project_description.md          (5min)  粘到简历上
```

### 📝 场景 B：写简历

