## 七、组件规范

### 7.1 按钮
| 类型 | 样式 |
|---|---|
| Primary | 墨绿色背景 `#2D8A6E`，白色文字，圆角8px，高度40px |
| Secondary | 墨绿色边框，白色背景，墨绿色文字 |
| Danger | 红色 `#F56C6C` 背景，白色文字 |
| Text | 无背景无边框，墨绿色文字 |
| Large | 宽度100%，高度48px，字号1rem |

### 7.2 输入框
- 边框色 `#E0DCD3`，聚焦时边框色 `#2D8A6E`
- 圆角 8px，高度 40px
- Placeholder 色 `#A0A0A0`

### 7.3 卡片
- 白色背景，圆角 12px，阴影 `shadow-sm`
- 内边距 16px
- 悬停时阴影升为 `shadow-md`，上移 2px

### 7.4 标签 (Tag)
- 圆角 6px，内边距 2px 8px，字号 0.75rem
- 成功: 绿底绿字，警告: 橙底橙字，危险: 红底红字

### 7.5 弹窗 (Dialog)
- 圆角 16px，阴影 `shadow-lg`
- 标题居中，16px 加粗
- 按钮组居右

### 7.6 Loading
- 统一使用 Element Plus `v-loading` 指令
- 加载文案 "加载中..."

### 7.7 空状态
- 居中灰色图标 + "暂无数据" 文字
- 图标色 `#A0A0A0`

### 7.8 错误页
- 居中显示错误图标 + "页面加载失败" + "重试"按钮

## 九、动画规范

| 场景 | 动画 | 时长 |
|---|---|---|
| 页面切换 | fade + slide | 300ms |
| 卡片悬停 | scale + shadow | 200ms |
| 弹窗打开 | scale + fade | 300ms |
| Loading 出现 | fade | 200ms |
| 列表项进入 | stagger fade-in | 50ms/item |
| 数字滚动 | count-up | 800ms |

### CSS Transition Token
```css
--transition-fast: 150ms ease;
--transition-normal: 300ms ease;
--transition-slow: 500ms ease;
```
